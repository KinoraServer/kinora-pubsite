## Why Kinora

<CardGrid>
  <Card title="Tiny and fast" icon="rocket">
    One Rust binary with the web app built in, SQLite for storage and FFmpeg for video.
    Runs happily on a NAS.
  </Card>
  <Card title="GPU transcoding" icon="setting">
    NVENC, Quick Sync, VAAPI and VideoToolbox, each checked with a real test encode,
    with CPU fallback when no GPU is there.
  </Card>
  <Card title="HDR and Dolby Vision" icon="star">
    HDR10, HLG and Dolby Vision detection. Profile 8.1 plays as HDR10 without transcoding,
    and tone mapping to SDR when a screen needs it.
  </Card>
  <Card title="Picks the right tracks" icon="comment-alt">
    Remembers your audio and subtitle choices per show and library, so the next episode starts the way
    you like it.
  </Card>
  <Card title="Themes and modules" icon="puzzle">
    Six built-in themes with light and dark modes, plus your own JSON themes. Turn off any
    module you don't use.
  </Card>
  <Card title="Android TV" icon="laptop">
    A native app that direct-plays what your TV can decode, Dolby Vision included. Tested on
    the NVIDIA Shield.
  </Card>
</CardGrid>

## Up and running in a minute

```bash
docker run -d --name kinora -p 8420:8420 \
  -v /path/to/config:/config \
  -v /path/to/media:/media:ro \
  ghcr.io/lancealthouse/kinora:latest
```

Then open `http://<server-ip>:8420` and create your account.
See the [Docker guide](/docs/install/docker/) for GPUs and compose, or the
[Unraid guide](/docs/install/unraid/).

Kinora is free and open source under the GPL-2.0 license. Wondering how it stacks up against
Jellyfin, Plex or Emby? See the [honest comparison](/docs/compare/).
